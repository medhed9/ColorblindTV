  # ColorblindTV

   See colors more like others see them.

   ColorblindTV is free Windows software for people with red-green colorblindness.
   It corrects everything shown on your PC, including Netflix, YouTube and other
   services in Edge or Chrome, as well as PC games.

   **Download:** see the Releases section on the right.

   If Windows shows "Windows protected your PC," click More info → Run anyway.

   More information: https://colorblindtv.com
